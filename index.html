Prepare the controller

  1. Connect the controller to this computer with a USB cable.
  2. That is all — the updater puts the controller into update mode by itself.

The screen of the controller stays off in update mode — that is normal.

First time on a new computer or phone, the app asks you to pick the USB device from a list — just follow the on-screen prompts.

Controller with very old software?
  1. Press and hold the BOOT button.
  2. Press and release RESET, then release BOOT.

Not in the list? Put the controller in update mode
  1. Press and hold B (BOOT).
  2. While still holding B, press and release R (RESET).
  3. Now release B, then press the button above.

The controller's screen stays off in update mode — that is normal. Only controllers with very old software need this.
